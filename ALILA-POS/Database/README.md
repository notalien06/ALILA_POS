# Database Documentation

## Database Name
largo

## Database Management System
Microsoft SQL Server

## Connection
The application connects to the `largo` database using SQL Server Express.

## Setup
1. Open SQL Server Management Studio (SSMS).
2. Connect to your SQL Server instance.
3. Open `ALILA_POS_Database.sql`.
4. Execute the script to create the database tables and relationships.

## Notes
This script contains the database schema only. It does not include the original records provided by the professor.
